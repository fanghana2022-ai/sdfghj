## 一、程式用途與使用說明

本程式是一個簡單的 Python 聚餐費用試算工具，主要運用了變數、數字運算、布林值、字串處理與基本輸出等基礎技巧。程式會自動執行以下流程：
1. **處理字串資料：** 將聚餐名稱去除頭尾空白並轉為小寫。
2. **清理與型別轉換：** 將含有符號與逗號的餐費文字清理並轉換為浮點數，將人數文字轉為整數。
3. **分步計算：** 依序計算「服務費」（以原始餐費 10% 計算）、「應付總額」（原始餐費 ＋ 服務費 － 折價券）以及「每人分攤費用」。
4. **預算判斷：** 使用比較運算判斷每人費用是否超過每人預算（300元），輸出布林值結果。
5. **完整三組測試：** 分別驗證不同人數與折價券設定下的計算結果。

## 三、作業問答題

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
**答：** 
因為 `"4"` 在 Python 中是 `str`（字串）型別。字串代表的是文字，如果在 Python 中直接進行除法運算（例如 `"1220" / 4`），系統會直接報錯（`TypeError`），因為電腦無法對純文字進行數學除法。必須先使用 `int()` 將其轉換為整數（數值型別），程式才能正確進行「應付總額 ÷ 分攤人數」的數學計算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**答：**
* **計算過程與結果：**
  1. 先扣折價券：$1,200 - 100 = 1,100$ 元
  2. 再計算 10% 服務費：$1,100 \times 0.10 = 110$ 元
  3. 應付總額：$1,100 + 110 = 1,210$ 元（每人費用為 $1,210 \div 4 = 302.50$ 元）
* **為什麼不同：**
  題目規定的應付總額是 **1,220 元**。兩者不同的原因在於**計算基準點**不同。餐廳實務上通常是以「原始餐費」作為計算服務費的基底（即 1,200 的 10% 是 120 元），折價券則是店家或平台給予的折扣優惠。如果先扣折價券再算服務費，會導致服務費的收取金額變少（從 120 變 110），這不符合題目所要求的計算規則。
